# Alibhhars Learn History

Build a professional Arabic educational platform named

"Al-Ibhhar Platform | منصة الإبحار".

The platform is dedicated to teaching history.

Instructor: Mr. Saeed Sayed Abdel Fattah Matar.

Designed and developed by Engineer Ziad Ali Mohamed Khuzaym.

DESIGN:

- Arabic-first interface.

- Right-to-left (RTL) layout.

- Deep navy blue, gold, and white colors.

- Professional, modern, lightweight design.

- Fully responsive on mobile, tablet, and desktop.

LOGIN PAGE:

- Make the login page the initial screen.

- Include a User ID field.

- Include a Password field.

- Include a Login button.

- Include a WhatsApp button for requesting an account.

- Do not include a public sign-up option.

STUDENT DASHBOARD:

Create two main sections:

1. Video Lectures.

2. Educational Exercises and Quizzes.

ADMIN DASHBOARD:

Create a separate administrator interface with pages for:

- Student account management.

- Video lecture management.

- Exercise management.

- Student results.

- Platform settings.

IMPORTANT:

Students must not be able to create their own accounts.

Only the administrator can create student accounts.

Create the initial interface and page structure first.

Use realistic Arabic text and a clean educational design.

Do not pretend that authentication, database operations,

or video uploads work until the backend is implemented.
